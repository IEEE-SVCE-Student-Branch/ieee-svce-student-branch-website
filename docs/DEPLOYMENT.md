# Deployment

## Infrastructure
- **Frontend**: Edge network (e.g., Vercel, Cloudflare Pages, Netlify).
- **Backend/API**: Serverless functions or standard PaaS container (e.g., Render, Heroku).
- **Database**: Managed DB service.

## Principles
- Infrastructure as Code (IaC) preferred.
- Future IEEE SVCE committees must be able to maintain the system without the original developers. Keep it simple.

## DECISION REQUIRED
- What is the approved budget for deployment hosting, guiding the choice of platforms?
