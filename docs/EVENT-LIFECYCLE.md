# Event Lifecycle

## Phases
1. **Ideation & Planning**: Draft event details in the private OS.
2. **Approval**: Committee review.
3. **Promotion**: Event is published; Creative Experience Engine is used to generate promotional pages from standard components. (Never hardcode event info into presentation components).
4. **Execution**: Real-time management, attendance tracking.
5. **Post-Event**: Archiving, uploading media, capturing evidence/provenance, syncing reports.
