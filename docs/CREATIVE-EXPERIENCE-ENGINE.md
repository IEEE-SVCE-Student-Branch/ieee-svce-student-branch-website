# Creative Experience Engine

## Purpose
Allows committee members to build rich, dynamic event pages and campaigns without writing code, avoiding one-off templates.

## Architecture
- Composes approved UI components and layouts.
- Adheres strictly to the institutional design system.
- It must not generate arbitrary production HTML/CSS that bypasses the design system.

## DECISION REQUIRED
- Will the Engine use a headless CMS visual editor, or a custom-built component composer?
