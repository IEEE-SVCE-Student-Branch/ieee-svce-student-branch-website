# Archive

## Mission
Serve as the permanent institutional memory of the IEEE SVCE Digital Institution.

## Policies
- Never delete historical institutional records without explicit policy.
- Historical content must remain reproducible.
- Every important public entity must have a stable URL.

## Technical Approach
- Soft deletes for all database records.
- Immutable storage for critical media.
- Static snapshots of past years if platform changes significantly.

## DECISION REQUIRED
- How will static snapshots of old sites be hosted to ensure URLs remain stable indefinitely?
