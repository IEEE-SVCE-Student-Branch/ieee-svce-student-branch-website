# Data Model

## Overview
The data model represents the core entities of the IEEE SVCE Digital Institution.

## Core Entities

1. **User / Member**
   - Profile information, roles, and membership details.

2. **Event**
   - Title, date, location, description, status.
   - Relationship to Organizers and Attendees.

3. **Project**
   - Repository of student/branch projects.

4. **Resource / Media**
   - File metadata, URL, asset type.

5. **Committee Term**
   - Represents a specific academic year's committee.

6. **Knowledge Graph Nodes**
   - Connections between Events, Projects, People, and Topics.
